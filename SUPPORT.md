# Getting help

- **Usage questions and "is this a bug?":** open an issue using the **Question** template. Include the output of `killpoint doctor` and the relevant `report.json` (it is redacted by default, but check it first).
- **Bugs:** use the **Bug report** template.
- **Ideas for new scenarios or integrations:** use the **Feature or scenario proposal** template. Please read [CONTRIBUTING.md § Scope](CONTRIBUTING.md#scope) first.
- **Security issues:** see [SECURITY.md](SECURITY.md). Do not open a public issue.

killpoint is maintained by one person in their spare time. Responses are best effort.
